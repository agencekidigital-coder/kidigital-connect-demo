# Catalogue des ateliers publics et préparation Google
La migration naitea_public_workshop_catalog_and_google_place_id crée un slug stable unique par professionnelle, réservé via RPC authentifiée avec auth.uid(), et une projection catalogue limitée aux ateliers publiés de ce compte. La page /ateliers/<slug> est ouverte à partir de Partager mes ateliers. Génération explicite, nom commercial requis; aucun slug existant n'est modifié. Les ateliers à venir sont affichés par défaut, filtres présentiel/visio, ateliers passés accessibles, pagination 24 cartes. Même lien pour iframe HTTPS (?embed=1) avec détails dans l'iframe. Pas de réservation, noindex, no-store, production désactivée. Aucun changement de statut d'atelier.
Google : Place ID facultatif stocké par propriétaire, pas de notes inventées, pas de stockage de données Google.
