The return page GET only reads database state. An explicit same-origin POST refresh can recover a missing notification by reading the stored session and verifying it directly with Stripe on the bound connected account. Webhook delivery remains mandatory for unattended confirmations. DB settlement is idempotent, email is attempted by the first successful confirmation only. If mail fails it requires manual follow-up, not another payment.
