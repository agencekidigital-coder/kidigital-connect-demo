# Controlled checkout pilot
The platform webhook is enabled in Stripe test mode and Cloudflare reports workshopCheckoutConfigured=true. Delivery and end-to-end payment are not yet verified. The database publication migration permits only the single existing eligible online draft, keeps other online modes blocked, and preserves on-site and free workshops. The API restricts publication to the configured preview origin. The UI uses the checkout configuration flag, but the database remains authoritative. Never use real card or family data. The first test must verify Checkout, Stripe event delivery, database settlement, email, and the professional's payment status. Do not extend the scope or enable real payments before completing reconciliation/refunds and tests.
