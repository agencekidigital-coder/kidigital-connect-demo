# Publication des ateliers — Preview
Migration appliquée naitea_public_workshop_projection : fonction de projection publique par UUID, exécution privilégiée cantonnée à naitea_private, wrapper public invoker, aucun droit de lecture anonyme sur les tables privées. Projection uniquement pour published, champs publics limités, nom commercial si renseigné. Le chemin technique de couverture (UUID propriétaire/atelier) figure dans la réponse RPC mais pas dans la page HTML. Bucket privé; policy anon limitée aux opérations de lecture de couverture publiée, sans listage ni création de liens signés. L'owner garde accès en lecture aux covers publiées, écriture uniquement en brouillon. Test SQL transactionnel effectué : brouillon invisible, publication visible, dépublication invisible. Aucune publication persistante.
Le lien /atelier/<uuid> est stable, rendu serveur et sans données encodées dans l'URL. Page utilisant classes, styles et charte originaux de Codex, sans code de démo. Réservation désactivée, aucun compte famille ou paiement créé. Photo proxy same-origin, vérification du statut à chaque requête, type JPEG et limite 2 Mio; no-store, noindex. Dépublication ne peut pas effacer les copies ou liens signés antérieurement créés par le propriétaire.
Action explicite de publication d'un brouillon complet, confirmation des champs rendus publics, dépublication préalable aux modifications, aperçu privé et partage/copie. La publication est activée uniquement dans la branche Preview via flag. Les anciens liens de démo restent des liens fictifs et ne donnent pas accès aux vraies données. Pas de référencement ni d'annuaire à cette étape.
Tests automatisés ajoutés; vérifier compilation Cloudflare, accès anonyme par lien et photo, dépublication, isolation propriétaire, partage et version mobile dans navigateur avant utilisation réelle. Le projet Supabase est partagé avec la bêta, mais aucune donnée existante n'a été publiée. Ne publier que des exemples fictifs lors des tests. Le rendu côté familles reste sans réservation.
