Le site sert les 24 WebP officiels. Les PNG et les planches PDF correspondent aux mêmes images ; ils restent dans les fichiers source fournis pour éviter leur duplication dans le chargement du SaaS. Les logos PNG, la palette et les fichiers Naitea Titres sont copiés sans modification.

Palette : pourpre `#590425`, corail `#BF5B45`, moutarde `#D89328`, ivoire `#FEF8ED`. Le pourpre porte les textes et les actions. Les icônes de navigation restent simples ; les images 3D sont employées dans les contenus et le studio.

La police de titres est le prototype **Naitea Titres SemiBold**, dérivé de Baloo 2. La licence et les instructions originales se trouvent dans `typographie/OFL.txt` et `typographie/LISEZ-MOI.txt`.

Source Sans 3, police d’interface indiquée par la charte, est distribuée localement avec sa licence SIL OFL :

- https://github.com/google/fonts/tree/main/ofl/sourcesans3
- `typographie/SourceSans3-Variable.ttf`
- `typographie/SourceSans3-OFL.txt`

Ne pas attribuer les photographies de démonstration aux clientes de la professionnelle. Leurs sources restent dans `assets/photos/SOURCES.md`.

## Dérivés transparents du 20 novembre 2026

Le logo et les 24 pictogrammes employés par l’interface sont désormais les PNG de `transparent/`, détourés avec l’outil de génération/édition d’images à partir des fichiers officiels. Le vrai canal alpha a été contrôlé sur chaque fichier. Les originaux dans `logos/` et `pictogrammes/` restent inchangés.

Les trois premiers pictogrammes et le logo avaient été préparés pour les stories ; les 21 autres ont été détourés dans cette passe. Les fichiers de génération originaux sont conservés dans `/workspace/generated_images/`. Aucun pictogramme officiel n’est proposé dans les bibliothèques de création des professionnelles ; leurs propres imports restent disponibles.
